---
title: Mini Guia de Lógica de Programação
---

Este um mini curso de lógica de programação em Python e JavaScript, ao mesmo tempo. Ao final dele, tu vai aprender não só por completo a lógica de programação, como também o básico de Python e JavaScript, além de já conseguir fazer coisinhas bem legais e úteis no terminal! Parece loucura aprender as duas linguagens ao mesmo tempo, mas não é: as duas utilizam a mesma lógica, pensamento computacional, e nós vamos treinar isso. E, caso tu realmente não queira, será possível também trabalhar só com uma linguagem também.

## Como vai funcionar?
O guia é dividido em **6 unidades** com explicações profundas e práticas, e no final de cada unidade há exercícios para prática e fixação dos contéudos. No curso, vão ter seções com a demonstração dos comandos em Python e em JavaScript, assim tu pode escolher em qual linguagem programar ou até mesmo programar com as duas ao mesmo tempo. Recomendo fortemente tentar fazer as duas juntas. Independente disso, tu pode ou:
- **Caso tu seja iniciante e não saiba de nada:** Fazer ele todo em ordem, seguindo cada conteúdo conforme a numeração e fazendo os exercícios certinhos para entender bem
  
ou...
- **Caso só reforçar alguma coisa que não esteja bem clara:** Ir direto pra unidade correspondente e ler o conteúdo ou só pegar os exercícios mesmo.

## Do que eu preciso?
Paciência pra aprender, qualquer editor de texto/código e instalar o interpretador de Python e o de JavaScript no teu computador. Interpretador é uma ferramenta que o teu computador vai usar pra entender teu código.

_Pra isso é só..._

### Se tu estiver no Windows:
- **Pra baixar Python:** Abrir o cmd e digitar:
```sh title="Instalar Python no Windows"
winget install Python.Python.3
```

- **Pra baixar o NodeJS:** Seguir o passo a passo no site do Node:
[Baixar o Node.js](https://nodejs.org/pt-br/download).

### Se tu estiver no Linux:
- **Pra baixar Python:** Abrir o bash e digitar:
```bash title="Instalar Python no Linux"
sudo apt update
sudo apt install python3 python3-pip
```

- **Pra baixar o NodeJS:** Seguir o passo a passo no site do Node:
[Baixar o Node.js](https://nodejs.org/pt-br/download).

### **E agora?**
Agora, é só invocar no bash ou no cmd `py/node "caminho do arquivo do código"` para o interpretador de cada linguagem interpretar o código. Use py para Python e node para JavaScript.
